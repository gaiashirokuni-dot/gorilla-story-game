KUNIO STORY V2.0 完成版（GitHub Pages用・フラット構成）

■ 遊び方
index.htmlを開くとゲームが始まります。
スマートフォンでの縦画面プレイを推奨します。

■ GitHub Pagesへの設置
このZIPを展開し、中に入っている全ファイルをリポジトリの直下へアップロードしてください。
フォルダを作る必要はありません。
古い同名ファイルがある場合は、今回のファイルですべて上書きしてください。

■ 実装内容
・実写写真ベースの立ち絵4差分
・普通／筋トレ／ポケカ／変なデートの4ルート
・全選択肢に専用リアクション
・8種類のエンディングと実写CGコレクション
・GORILLA LEVEL 80％以降の画面変化／100％SECRET END
・名前入力（端末内のみで使用）
・AUTO／既読SKIP／BACKLOG／SETTINGS／MENU
・オートセーブ／CONTINUE／手動保存／1つ前の選択へ戻る
・テキスト速度／AUTO待ち時間／SE音量設定
・iPhone SE相当の小型画面、ノッチ／ホームインジケーター対応
・キーボード操作、モーション軽減設定対応

■ 音について
BGMは使用していません。
ボタン操作時などの短いSEのみブラウザ内で生成します。
SEはSETTINGSから音量を0にできます。

■ セーブデータ
進行状況・END回収状況・設定は、プレイした端末のブラウザ内に保存されます。
別の端末や別のブラウザには引き継がれません。
